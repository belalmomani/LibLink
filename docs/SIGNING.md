# توقيع التطبيق وتحديثه دون حذفه
أندرويد يقبل التحديث فقط إذا (1) وُقّع APK بنفس المفتاح، و(2) كان versionCode أكبر.
- بدون مفتاح ثابت يولّد كل بناء على GitHub مفتاح debug جديدًا فيظهر «حزمة التثبيت تتعارض مع حزمة حالية».
- الحل: مفتاح واحد يُحفظ في أسرار المستودع (لا في الكود): `QH_KEYSTORE_BASE64`, `QH_KEYSTORE_PASSWORD`, `QH_KEY_ALIAS`, `QH_KEY_PASSWORD`.
- versionCode = رقم تشغيل الـWorkflow (يزداد تلقائيًا).
- **احفظ نسخة من ملف المفتاح وكلمته**: فقدانهما يمنع أي تحديث لاحق.
- أول مرة بعد تفعيل هذا النظام يلزم حذف النسخة القديمة مرة واحدة (موقّعة بمفتاح مختلف)، وبعدها كل البنايات تُحدَّث فوقها.
